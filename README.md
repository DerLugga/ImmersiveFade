# ImmersiveFade
This is an UI Addon for World of Warcraft Forever (Beta 1.60.1) that fades several UI elements based on ingame Events

core.lua has been rewritten for v0.2.0-alpha. Perfomance has been drastically improved. Not Fading out when Player is not full health/mana not functional.

Release Version v0.1.0-alpha was heavily written by AI for proof of concept and getting into Addon making. Future version will be made with the help of AI but not entirely written by it
